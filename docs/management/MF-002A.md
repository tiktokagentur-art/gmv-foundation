## Validation and boundaries

The four strict Pydantic models in app/management/schemas.py validate domain payloads. The JSON document at api/schemas/management-v1.schema.json is an envelope-only transport contract; it is NOT a complete domain JSON Schema. Consumers MUST validate payloads with the matching Pydantic model. No API endpoint is registered.

Organizational status never confers technical authority. The offline policy requires an active, reviewed, technically verified profile, a verified unblocked identity, a matching employee ID, current mandate version and explicit scope. Unknown scopes fail closed. Self-approval and declared reviewer conflicts are denied. A separate Control Plane must perform real authentication, authority checks and decision-context validation.
