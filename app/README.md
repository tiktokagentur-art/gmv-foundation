# Anwendung

Platzhalter. In diesem Verzeichnis liegt kein Anwendungscode.

Python / FastAPI ist ein Vorschlag und nicht beschlossen
([ADR-0002](../docs/adr/0002-python-fastapi.md)). Solange dieses ADR `Proposed` ist,
entsteht hier kein Dienst, kein Framework und keine Abhängigkeit.

`scripts/validate_structure.py` erwartet in `app/` ausschließlich diese Datei.
Anwendungscode setzt ein angenommenes oder ersetztes Backend-ADR voraus. Derselbe
Pull Request passt die Strukturprüfung an.
